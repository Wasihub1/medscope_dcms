# ==============================================================================
# MedScope DCMS — Project Dependencies & Installation Specification
# ==============================================================================
# This file defines all dependencies required to install and run both the
# Modern Full-Stack (FastAPI + React 19 + PostgreSQL) and the Streamlit Monolith.
#
# QUICK START GUIDE:
# ------------------------------------------------------------------------------
# 1. System Prerequisites:
#    - Python: 3.10+ (Python 3.14 tested)
#    - Node.js: 20+ and npm
#    - PostgreSQL: 18 running on 127.0.0.1:5432 (database: medscope_dcms)
#
# 2. Install Backend Python Dependencies:
#    python -m pip install -r requirements.txt
#
# 3. Install Frontend Node.js Dependencies:
#    cd frontend
#    npm install
#
# 4. Initialize Database Schema & Run Migrations:
#    python -m alembic -c backend/alembic.ini upgrade head
#    python backend/scripts/seed_components.py
#
# 5. Start the Services:
#    - Backend API:  python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
#    - Frontend UI:  cd frontend && npm run dev (http://127.0.0.1:5173)
#    - Legacy App:   python -m streamlit run "DCMS V1.py" --server.port 8501
# ==============================================================================
